# Мухаказик — азартные игры для дрозофилы

Ироничный прототип гэмблинг-механик про муху с оцифрованным мозгом. Один файл `index.html`, three.js с CDN, никакой сборки. Валюта — нейроны, стартовый баланс 166 700 (столько нейронов в MaleCNS v1.0, полной карте нервной системы самца дрозофилы). Баланс, коллекция, история и настройки лежат в `localStorage`.

## Запуск

Открыть `index.html` в браузере двойным кликом — работает с `file://`. Нужен интернет: three.js и шрифты грузятся с jsDelivr и Google Fonts.

Если браузер капризничает с `file://`, поднять любой статический сервер в этой папке:

```bash
python -m http.server 8765
```

и открыть `http://localhost:8765`. Для GitHub Pages достаточно положить файл в репозиторий как есть.

## Пять механик

| Вкладка | Аналог | Суть | Математика |
|---|---|---|---|
| 🩴 Тапок | Mines | Муха прыгает по клеткам на клетчатой скатерти. Под клеткой — вкусняшка и рост множителя или тапок. Забирай в любой момент. Волатильность — число тапков. | `×(k) = RTP · Π (25−i)/(25−m−i)` при любой стратегии |
| 🏓 Мухобойка | Aviator / crash | Муха летит к солнцу, множитель растёт как `2^(t/5с)`. Забери до мухобойки. Долетела до солнца — ×100. | `crash = max(1, RTP/U)`, то есть `P(crash ≥ x) = RTP/x` |
| 🎰 Мухогача | Гачапон / лутбокс | Автомат с капсулами, в каждой — муха: комар ×0 (это не муха), обычная ×0.5, дрозофила ×1.2, зелёная ×2.5, неоновая ×5, золотая ×10, бриллиантовая ×25. Гарант редкой+ каждые 40 капсул, ×10 гарантирует дрозофилу, полная коллекция — бонус 25 000. | RTP через долю комаров, ≈ 97–98 % с гарантами (симуляция на 2 млн капсул) |
| 🏁 Гонки | Ставки на скачки (как гонки фатье в Star Wars Outlaws) | Шесть мух трёх классов в каждом заезде: две надёжные (~30 %, ×3), две тёмные лошадки (~12 %, ×7–9), две авантюры (2–5 %, ×20–45), со статистикой под класс. Выбираешь одну, они летят круг по треку на скатерти, первая на финише получает дихлофос и переворачивается лапками вверх. Победила твоя — выигрыш. | шанс задаёт класс, нормировка к 100 %, `× = RTP / P`; порядок финиша по Плакетту–Люсу, анимация подгоняется под результат |
| 🦆 Крути гуся | Crash | Рука хватает гуся за шею и раскручивает, шея вытягивается, каждый оборот головы — ×1.25. Забери, пока держится: гусь скажет «га-га-га». Не успел — шея ломается, язык наружу, крестики вместо глаз, «кря». Муха рядом потирает лапки. | та же формула, что у мухобойки: `crash = max(1, RTP/U)`, обороты ускоряются `0.55·t + 0.04·t²` |

Глобальный переключатель RTP (90 / 95 / 97 / 99 %) внизу применяется ко всем играм, каждая панель показывает свой RTP и волатильность. Случайность — `crypto.getRandomValues`. Кнопка ⓘ «математика» показывает формулы прямо в игре.

Управление: пробел — ставка/забрать; цифры на клавиатуре или нампаде набирают ставку без клика в поле, Enter подтверждает и играет, `+`/`−` меняют шаг; клик по ручке автомата — крутить; ☕ восстанавливает мозг.

## Как устроен файл

Всё в `index.html`, секции идут по порядку:

- CSS — палитра (`:root`), панели, кнопки, CSS2D-лейблы.
- `utils` — RNG, твины, форматирование, тосты, `cfg.rtp`.
- `audio` — синтезированные звуки на WebAudio, без файлов.
- `wallet` / `store` — баланс и `localStorage`.
- `models` — муха (со «скинами» для гачи), тапок, вкусняшки, кружка, частицы, след, капсула.
- `createMines`, `createCrash`, `createGacha`, `createRace`, `createGoose` — по одной сцене, камере и панели на игру; общий рендерер, bloom и цикл в конце файла.

Для отладки в консоли есть `__muha` (`__muha.games.mines.debug.start()`, `__muha.games.gacha.S.force = 6` для бриллиантовой мухи, `__muha.games.race.debug.pick(2)` и `.start()` и т. п.).

## Что можно докрутить

- Provably fair: seed + hash раунда вместо просто `crypto`.
- Мобильная раскладка сделана базово (панель снизу), не вылизана.
- Ещё атакующие для «Мухобойки» (лягушка, паук, электромухобойка), больше вкусняшек, больше мух в гаче.
